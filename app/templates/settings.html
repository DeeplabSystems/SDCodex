System & Update

Pull the latest core code and rebuild/restart the container by running update.sh. Because the app runs inside Docker, the actual git pull + docker compose up -d --build runs on the host: this button records an update request, and a small host-side watcher (scripts/ui-update-watcher.sh, typically on cron) applies it.

{{ sys_update.state|default('idle') }} {% if sys_update.version %}{{ sys_update.version }}{% endif %}
{{ sys_update.message or 'Idle — no update requested.' }}
Picks up the latest code the next time the host watcher runs (see notes below).
Host watcher — set this up once

The web app cannot run Docker itself (no Docker install inside the container). You must run the watcher on the host, e.g. via cron:

# every 5 minutes, as the user that owns the repo + Docker
*/5 * * * * /path/to/SDCodex/scripts/ui-update-watcher.sh --once

Or run it continuously in a terminal:

/path/to/SDCodex/scripts/ui-update-watcher.sh --watch
